# Парсер вакансий

Программа, которая будет получать информацию о вакансиях с разных платформ в России, 
сохранять ее в файл и позволять удобно работать с ней (добавлять, фильтровать, удалять).

## Стек 
Python, ООП, PostgreSQL, requests

## Установка
Ссылка на клонирование проекта:
https://github.com/MichaelMigachev/course_work_4

## Запуск
python main.py

1. Выберите название, например 'python'
2. Выбери платформу:
1 - HeadHunter
2 - SuperJob
0 - Выйти
3. Укажи количество вакансий (< 100)
